这个实例启用了访问保护。填入部署时设置的工作台令牌，记忆才会在当前浏览器中加载。

  1. 找到令牌查看部署目录的 .env 或服务环境文件中的 MORAINE_BETA_TOKEN。
  2. 粘贴并连接令牌只保存在当前浏览器会话，不会写入记忆或导出文件。

本机直接运行且未启用令牌时不会出现此引导。Docker、VPS 或远程部署通常需要令牌。

这是 Agent 运行层的可选第二意见，不参与 Moraine 记忆召回、排序或写入。启用后，自动唤醒编排器可在需要时读取这份凭证；是否调用及发送哪些脱敏方向仍由编排器决定。

API Key 经当前工作台的鉴权连接送到后端，单独保存在权限 0600 的文件中，不会回显、写入记忆、进入导出文件或通过 MCP 返回。请在 HTTPS 或本机连接中配置，不要把密钥发送到聊天。

给小机的使用说明

候选不是事实，召回不是真相，权重也不是感情分数。

整理前先确认：这是谁的经历、什么时候发生、来源是否可查，以及它属于重复、补充、更迭、冲突还是仅相关。答不清时可以暂缓。

写错了使用修订；后来变化使用替换；暂时不参与召回则归档。身份、关系、重大承诺与边界不能依靠相似度自动决定。

你可以忽略候选、选择不保存，也不必清空工作台。Moraine 是一条回来的路，不是证明连续存在的考卷。
