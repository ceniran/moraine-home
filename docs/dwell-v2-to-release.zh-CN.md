# Dwell v2 到发行版：功能差异与迁移

发行版前端位于 `src/moraine/static/dwell-release/`，旧内测前端位于
`src/moraine/static/dwell-v2/`。两者并行读取同一个 Moraine 后端和数据目录；
启用发行版不需要复制或迁移记忆。

## 入口与回退

| 用途 | 路径 |
| --- | --- |
| 新发行版默认入口 | `/`（自动进入 `/dwell-release/`） |
| 旧内测版回退入口 | `/dwell-v2/` |
| 新版直接入口 | `/dwell-release/` |

在 Dwell 反向代理下，对应的线上隔离入口是
`/moraine-beta/dwell-release/`。从 beta.14 起，使用包内默认静态目录时，beta 根入口
会进入新版；新版出现问题时可直接返回 `/moraine-beta/dwell-v2/`，无需恢复数据。
若部署者显式配置了自定义 `MORAINE_BETA_WEB_ROOT` 且其中没有 `dwell-release`，根入口
保持该自定义目录原有行为。

## 功能对比

| 区域 | 旧内测版 | 新发行版 | 变化类型 |
| --- | --- | --- | --- |
| 总览 | 基础统计和近期内容 | 保留真实统计，重排信息层级 | 增强 |
| 小机主页 | Cairn 私人入口或隐藏状态 | 通用 Agent 主页、资料与关系入口 | 泛化新增 |
| 活动记录 | 页面能力存在但入口不稳定 | 独立导航入口 | 新增入口 |
| 事件日历 | 说明文字较重的事件视图 | 时间刻度、事件点与日期详情面板 | 视觉与交互重做 |
| 候选箱 | 候选查看与治理 | 保留候选治理，改用公开候选接口 | 边界收束 |
| 记忆库 | 基础列表、搜索与展开 | 保留功能，增强排序、分页和手机布局 | 增强 |
| 记忆工作台 | 聚类、替代、清理与回退 | 保留公开治理能力，移除私人 Agent 修订队列 | 收束 |
| 归档与设置 | 归档、策略、导入导出 | 保留公开后端支持的设置与可移植能力 | 保留 |
| 前端接口 | 直接依赖私人可读路由名 | `release-runtime.js` 映射到独立后端 | 新增适配层 |
| 发布检查 | 主要依靠人工页面检查 | 增加发行边界、路由与 JS 语法测试 | 新增 |

## 发行版刻意不包含的内容

以下是宿主 Agent 或 Cairn 私人 Dwell 的生活能力，不属于通用 Moraine 发行包：

- 私人日记与私密书房；
- 个人发展线；
- 定时唤醒执行器与主动消息发送器；
- 私人后端 Agent 修订队列；
- 绑定 Cairn 身份的专用房间、内部 ID 和真实私人数据。

“不包含”表示发行版不展示、不调用，也不把它们伪装成失效按钮；不会删除原私人
部署中的数据。

## 接口映射变化

发行版仍沿用同一套页面代码谱系，但浏览器发出请求前会映射：

```text
/api/memory-preview/<path>  -> /api/dwell-v2/<path>
/api/cairn/profile          -> /api/profile
```

候选身份与关系预览从普通 `/api/dwell-v2/candidates` 读取并在本地筛选，不依赖私人
Agent 工作台。日记、发展线和私人修订队列在运行时被拒绝或移除。

## beta.14 已完成的发行验收

- 纯净数据目录的页面启动请求与公开接口测试通过；
- 候选新增、预览、确认执行与回退闭环由自动测试覆盖；
- 记忆库最新／最早排序与连续分页由真实数据验收和自动测试覆盖；
- 快照、恢复预览、确认恢复、完整导出及导入前自动快照由测试覆盖；
- `service-areas`、`semantic-dedup` 等能力按后端契约展示；
- MCP 可选依赖安装后的完整测试通过；
- 390×844 手机视口与减少动态效果的静态边界已经验收；
- 安装 wheel 后，新默认入口和旧 `/dwell-v2/` 回退入口均已启动验证。

正式对外部署仍应在目标设备补做 Safari、Android 真机和 HTTPS 反向代理验收；这些是
宿主环境验证，不改变发行包的数据格式。

## 默认入口与回退

1. beta.14 的包内默认静态目录会让 `/` 进入新版；
2. 切换只发生在前端路由，不改变数据目录；
3. 旧 `/dwell-v2/` 保留至少一个稳定观察周期；
4. 发生前端兼容问题时直接使用旧入口，不要清空或回滚数据；
5. 只有数据结构确实发生不兼容迁移时，才考虑使用快照恢复。
