# 公开发行隐私检查

Moraine 的公开仓库与安装包只应包含程序、通用文档和合成示例。维护者或测试者的真实记忆、关系数据、邮箱、访问令牌、生产路径、服务地址、索引与数据库都不属于发行内容。

## 每次发布前

1. 运行 `scripts/check-release.sh`，检查常见凭证格式、生产路径、真实服务地址与维护者专用示例；
2. 构建 wheel 和 sdist，并对解包后的文件再次执行同类扫描；
3. 在空目录和全新虚拟环境安装 wheel，确认默认数据是合成示例，根入口与回退入口均可工作；
4. 核对 `NOTICE.md`、CDN 版本与 Subresource Integrity 值；
5. 检查 Git 状态和构建清单，避免把 `.env`、数据库、索引、日志、导出包或本地缓存加入提交。

## 兼容字段

旧版本曾使用带维护者代号的模块键和治理签名键。它们只作为已有实例的数据迁移别名保留，不是默认人物资料，也不会生成对应的私人内容。新界面、文档与合成测试统一使用 `Agent`、`用户` 或虚构人物。

## Git 历史

当前发行检查覆盖当前提交与构建产物。若历史提交曾包含真正的凭证、私人数据或仍可访问的内部地址，应先轮换凭证、下线地址，再单独评估历史重写。历史重写会改变提交哈希与标签，不能作为普通版本更新静默执行。
