# 从私人实例整理纯净版：发布边界

这份清单是发布门槛，不是要求用户迁移私人数据。

## 可以进入纯净版

- 与具体人物无关的记忆、候选、事件与版本数据契约；
- 候选事件篮子、抽取式整合、完整来源时间线；
- 本地向量检索与明确的关键词降级；
- 强度调整、归档恢复、审计事件与导入前快照；
- 手机前端、合成示例、相对路径配置和通用部署模板；
- 项目署名、许可证、第三方依赖说明与免责声明。

## 不进入纯净版

- 真实记忆、候选正文、关系节点、邮箱线程和私人日记；
- API 令牌、OAuth 文件、浏览器登录态、真实域名与服务器路径；
- 私人 Telegram 会话、自主醒来、书房、生活账本和生产 systemd drop-in；
- 只对单一家庭实例成立的固定人物名、账号、端口或上游服务；
- 历史备份文件、运行日志、缓存、向量模型权重和本地索引。

## 配置映射

| 私人实现中的依赖 | 纯净版处理 |
| --- | --- |
| 固定候选文件 | `MORAINE_BETA_DATA_FILE` 中的通用 candidates 数组 |
| 固定记忆服务 | 本地 JSON 权威文件；向量索引可从它重建 |
| 固定前端目录 | `MORAINE_BETA_WEB_ROOT` |
| 固定身份与关系服务 | 不默认启用；以后以明确插件接口接入 |
| 固定语义上游 | `MORAINE_SEMANTIC_URL` 与独立令牌 |
| 真实初始化数据 | `src/moraine/data/beta-seed.json` 合成示例 |

## 发布前必须通过

1. `scripts/check-release.sh` 无敏感路径或凭证命中；
2. 全新临时目录可从合成示例启动；
3. 候选预览不写入，确认后才产生长期记忆；
4. 日历按事件时间统计，来源时间线从早到晚；
5. 赋权、归档、恢复和导入都产生审计或恢复点；
6. 本地向量服务不可用时，页面明确显示关键词降级；
7. 390×844 手机视口可完成主要操作；
8. 许可证、NOTICE、部署说明和备份警告随包分发。
