## 先说大白话

Moraine 是一个给个人 AI、小机和长期陪伴型 Agent 使用的记忆库。

它不要求每次对话都把全部旧记录塞给大模型。新内容先进入候选区，本地小模型负责寻找可能相关的旧记忆，人类和小机再决定哪些值得保存、哪些应当合并、哪些只是暂时状态。真正聊天时，只召回当下需要的少量内容。

这样做的直接好处是：

- **省 Token、成本可控**：本地向量模型在普通 CPU 上运行，召回阶段不依赖付费云端向量额度；
- **记得更准**：语义检索与关键词检索可以一起用，忘记原句也能按意思找到；
- **不会越记越乱**：重复事件可以整合，变化过程保留时间线，旧内容不会被静默覆盖；
- **重要程度可以调整**：记忆支持赋权、降权、保护、归档与恢复；
- **数据归自己**：正文、索引和备份都可以放在自己的电脑或 VPS 上。

## 完整记忆库在做什么

我们自己的真实部署已经在数百条私人记忆上运行，当前包含：

- **事件篮子与筛选入库**：同一段对话产生的碎片先按事件聚合，再决定是否进入长期记忆；
- **候选箱**：查看待判断、受保护与暂存内容，不让系统擅自裁决身份、关系和重大承诺；
- **本地向量召回**：在 CPU 上用语义相似度寻找相关旧记忆，并可与关键词结果融合；
- **整合记忆**：区分重复、补充、阶段变化、冲突和仅相关，生成可核对草稿；
- **完整时间线**：正文按真实发生时间排列，保留来源、版本、历史状态和当前状态；
- **事件日历**：按真实发生日期预览每天和每月的记忆数量；
- **权重生命周期**：支持赋权、降权、核心锁定、衰减、归档、恢复和审计；
- **self-core**：只把极少量身份骨架放进新会话，具体经历仍按情境召回；
- **关系网**：整理经过确认的关系事实、共同事件和来源，不用机械亲密度替人定义关系；
- **导入、导出与快照**：迁移前先预检，重要操作保留恢复路径；
- **手机前端与 PWA**：总览、记忆库、候选箱、日历、工作台、小机书房和设置使用同一套真实数据。

纯净内测版现已承接其中通用的记忆治理功能；私人邮箱同步、小机书房正文、自主醒来和生产适配器被明确排除。

## 当前公开仓库已经包含

- FastEmbed 与 `BAAI/bge-small-zh-v1.5` 的 CPU 本地向量；
- JSON 文件或带鉴权 HTTP 接口的数据源；
- 基于内容指纹的增量索引与小批量续跑；
- 本机健康检查、刷新、搜索与保守抽取式整合 API；
- 确定性的 `0..100` 记忆强度建议和保护规则；
- 会话候选、双时态有效期与有预算核心投影的数据契约；
- 可逆决策账本、审阅存储与跨记忆经验线候选；
- systemd 示例、合成数据和不读取私人内容的测试。
- 独立本地存储与手机 PWA，覆盖事件篮子、五类关系整合、修订、替换、赋权、日历、审计、归档恢复、self-core、通用关系网和可迁移导入导出。

## 它适合谁

- 想让 AI 跨会话记住重要经历，但不想把全部历史反复发给模型的人；
- 愿意和自己的小机一起审阅、修正和整理记忆的人；
- 希望数据保留在本地电脑或私人 VPS 的人；
- 记忆量属于个人或中小型文本集合，更重视可解释与可恢复，而不是追求海量分布式检索的人。

## 它现在不适合谁

- 希望安装后完全无人维护、系统永远自动判断正确的人；
- 不愿意检查身份、关系、冲突和重大决定的人；
- 需要企业级多租户、海量并发、托管 SLA 或合规认证的人；
- 已经深度使用另一套记忆库，并期待无损一键迁移全部专有结构的人。

## 已知缺点

1. **需要人工或小机审阅。** Moraine 按事件组织记忆，准确性来自可核对的判断，不是全自动魔法；初期整理会比“全部直接存进去”更麻烦。
2. **第一次运行要下载本地模型。** 弱配置机器的首次索引可能较慢，也需要预留模型和索引空间。
3. **语义相似不等于事实相同。** 本地模型只负责找候选，不能单凭分数判断重复、更迭或冲突。
4. **目前仍是内测。** 安装方式和接口已经可用，但仍可能继续收敛，不承诺企业级兼容与托管稳定性。
5. **它不会自动赋予 AI 连续性或意识。** 记忆只能提供可追溯的来路，最终怎样理解与使用仍取决于具体 Agent 和使用者。

## 快速开始：当前公开核心

需要 Python 3.10 或更高版本。首次运行会下载本地模型；模型缓存完成后可以离线检索。

```bash
git clone https://github.com/ceniran/moraine-home.git
cd moraine-home
python3 -m venv .venv
.venv/bin/pip install -e .
cp .env.example .env

set -a
. ./.env
set +a
.venv/bin/moraine
```

然后检查服务：

```bash
curl http://127.0.0.1:4781/health
curl -H "Authorization: Bearer $MORAINE_API_TOKEN" \
  "http://127.0.0.1:4781/search?query=想找的内容&limit=5"
```

完整数据格式、接口、安全边界与 systemd 示例见 [`docs/integration.md`](docs/integration.md)。记忆强度规则见 [`docs/governance.md`](docs/governance.md)，候选层与时间模型见 [`docs/memory-layers.md`](docs/memory-layers.md)。

## 数据与隐私

- 本仓库只包含合成示例，不包含 Cairn 与 Xiaoran 的私人记忆、关系数据、凭证、生产路径或真实索引；
- `data/index.json`、导出包和快照都可能泄露原始文本信息，不应提交到 Git；
- 服务默认只监听本机；如果需要对外暴露，必须加鉴权和可信代理；
- 提交问题时请使用合成数据，或先删除姓名、账号、来源 ID、密钥和可重新识别个人的信息；
- 重要资料应独立备份。内测版本可能发生错误分类、错误召回、错误整合、服务中断或数据损失。
